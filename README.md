# 知序 · Study Studio

按自己的节奏，把知识变成能力。一个以长期掌握为目标的学习工作台：米白与墨绿双色、海报式字体与留白、响应式布局。

## 运行

需要 Node.js 22 或更新版本，无第三方运行时依赖，无需 API 密钥或外部资源。

```bash
npm run dev
```

默认监听 `0.0.0.0:3000`。可用 `PORT=3001 npm run dev` 修改端口。

```bash
npm run build   # 生成可独立部署的 dist/
npm start       # 运行 dist/，请先 build
npm test        # 6 组学习状态、复习、计时和输入处理检查
npm run test:browser  # 使用本机 Chromium 验证完整流程，需先启动服务器
```

浏览器测试默认使用 Chromium，可通过 `CHROMIUM_PATH` 指定路径、`TEST_URL` 指定测试站点。测试使用独立浏览器配置，不修改个人学习记录；整页与移动端截图保存于 `/tmp/zhixu-*.png`。

## 学习体验

- 今日只选一个知识点；内置「线性变换的核」「导数的直觉」「递归的思想」三组课程。
- 四阶段：建立理解 → 完整例题 → 独立练习 → 闭卷回忆。
- 独立答题支持多行文字；提示按需逐级展开，完整解答不会默认出现。
- 提示依次为概念、方法、下一步、完整解答；使用提示会安排巩固，查看完整解答后需换题独立练习。
- 依据自选节奏展开更细的解释或精简熟悉步骤；支持休息、仅补习概念／步骤，以及把困难留到明天。
- 模块始终用 ○ 表示未完成；四阶段及回忆自检均确认后才标记 ✓。
- 完成模块后按当地日历安排第 1、3、7 天复习；复习时不展示上次填写的回忆答案。
- 专注计时可暂停、继续、重置；后台标签页使用截止时间校正，不因计时结束而自动完成模块。
- 学习进度、答题草稿、节奏、提示和复习队列保存在本机 `localStorage`，刷新可恢复。

## 当前范围

当前是可独立运行的内置课程学习工具，**未接入实时 AI 服务**。少量已知表达使用规则识别关键结果，自由回答无法可靠判断时明确转为对照自检。完成标记代表学习者确认过练习与回忆标准，不代表模型或测评机构认证。

记录只存在当前浏览器与站点，没有账号同步或后台通知；清除站点数据会移除记录。站点无需网络加载图片、字体、脚本或课程。

## 文件

- `src/app.js`：页面、学习面板及交互。
- `src/styles.css`：双色视觉、响应式布局与减少动画支持。
- `src/courses.js`：课程内容、例题、提示、自检标准与 SVG 图示。
- `src/learning.js`：进度约束、复习安排、计时、持久化校验与答案规则。
- `scripts/serve.mjs`、`scripts/build.mjs`：开发／生产静态服务与构建。
- `docs/tutor-guide.md`：扩展课程或接入导师时遵循的教学规范。

## 只用 Chrome 的私有预览

[在浏览器中创建 Codespaces 私有预览](https://codespaces.new/Alencyayn/Self-Study-Web?ref=main)

1. 在 Chrome 打开上面的入口并登录自己的 GitHub 账号，点击 **Create codespace**。
2. 等待云端环境启动。仓库的 `.devcontainer` 配置会自动启动原有网站，并尝试打开 3000 端口预览。
3. 如果没有自动打开，在底部 **Ports** 面板找到 **3000 / 知序 Study Studio**，点击 **Open in Browser**。保持 **Port Visibility: Private**；GitHub 默认创建私有转发端口。

这不需要在 Windows 安装 Node.js、Git 或其他软件，也不使用 GitHub Pages。入口是创建云端预览的页面，不是已经运行的网站地址；实际地址会在 Codespace 创建后生成，需 GitHub 登录才能访问。Codespaces 使用 GitHub 账户的云开发额度，关闭或停止 Codespace 后网站预览也会停止。不要把端口切换为 Public。
